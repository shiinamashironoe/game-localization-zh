# 翻译批次说明（RPG Maker MZ 汉化通用模板）

> 项目特定部分（术语、角色、语境）由 `_localization/glossary.md`、`characters.md`、`style.md` 提供，本文件不变。

## 任务
把分配给你的批次逐条译成**简体中文**（自然华语，不要方言腔）。

- 输入：`_localization/work/batches/<批次>.jsonl`，每行 `{"id": "...", "src": "原文（\n 表示换行）"}`
- 输出：`_localization/translations/<批次>.txt`，纯文本块：

```
@@<id>
第一行译文
第二行译文
@@<id>
...
```

规则：
1. 每条以 `@@` + 原样 id 开头，随后是译文行。
2. 不写空行；原文空行省略。
3. 行数可少于原文（中文更短，允许合并），但**不得丢信息**。
4. 说话人单独一行的（人名），译成同样单独一行。
5. 每行不超过 **38 个全角字**，超出就拆行。

## 硬规则
- **控制码原样保留**：`\c[3]` `\C[0]` `\i[130]` `\v[62]` `\F1[haruna2_1]` `\FH[ON]` `\n[1]` `\ac[270]` `\ms[3]` `\>` `\.` `\|` `\{` `\^` `\$` 等，字符与数量必须与原文一致。
- 大写 `\C` 保持大写。
- **目标语言不留假名**。拟声词改中文（哈啊、咕啾、撸、啪、怦怦）。
- 专名、术语一律按 `glossary.md`；未收录的音译并在 `progress.md` 记一笔。
- 「」保留；标点用全角；省略号用 ……
- 成人内容按原尺度直译，不美化不删减。
- 插件标签（`<hint:...>` `<seen:...>` `<outfit:...>`、`if(...)` 前缀）原样保留。

## 自检（必做）
```
python <skill>/tools/check_batch.py <输入jsonl> <输出txt>
```
`kana=0 code_mismatch=0` 才算完成。报警按提示修，别绕过。checker 会先剥掉控制码再扫假名——
所以 `\HINT[レベルアップ]` 这类「控制码里的日文参数」不算残留（那些是查找 key，玩家看不到）。

## 回报
一行：`<批次> OK entries=N kana=0 code_mismatch=0`
