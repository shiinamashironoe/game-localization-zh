# R18 台詞與描寫句式庫

> 用途：H 場景最容易翻成「字幕腔」——一句一動詞、每句都「啊……」、情緒全用形容詞。
> 這裡給的是**功能句式**：先判斷這句在場景裡的功能（升溫／絕頂／求饒／命令／羞恥／挑逗／事後），再從對應層級挑寫法。
> 範例以簡中書寫；繁中專案照 `glossary-nsfw.csv` 的繁中欄換字（例：说→說、里→裡、什么→什麼），句式不變。

## 1. 功能句式

| 功能 | 日文常見句 | 軟 | 標準 | 粗 |
|---|---|---|---|---|
| 升溫 | あっ……そこ、気持ちいい…… | 啊……那里，好舒服…… | 那里……好舒服…… | 就那儿，舒服…… |
| 升溫 | なにこれ、変になっちゃう | 好奇怪……身体怪怪的 | 怎么会……感觉好奇怪 | 操，这什么感觉 |
| 忍不住 | もう我慢できない | 忍不住了…… | 快忍不住了…… | 憋不住了 |
| 絕頂 | イくっ……！ | 要去了……！ | 要去了……！ | 要射了／要到了 |
| 絕頂 | 一緒にイって | 一起……去吧 | 一起高潮吧 | 一起到 |
| 餘韻 | すごかった…… | 好厉害…… | 好厉害…… | 真他妈爽 |
| 求饒 | もうやめて…… | 别再…… | 别继续了…… | 停、停下 |
| 求饒 | お願い、許して…… | 求你了，放过我…… | 求你……饶了我 | 别……求你 |
| 命令 | もっと鳴いて | 再叫一点…… | 再叫大声点 | 叫啊 |
| 命令 | 自分で動け | 自己……动一下 | 自己动 | 自己动，别装死 |
| 羞恥 | 見ないで…… | 别看…… | 别看…… | 别盯着看 |
| 羞恥 | こんなの、恥ずかしい…… | 这样……好羞耻…… | 这样太羞耻了…… | 丢死人了 |
| 挑逗 | 欲しい？ | 想要吗？ | 想要？ | 想要就说 |
| 挑逗 | ここ、触ってほしいの？ | 想我摸这里吗？ | 想被摸这里？ | 求我摸啊 |
| 事後 | 中に出ちゃった…… | 射在里面了…… | 射在里面了…… | 全射进去了 |
| 事後 | 責任取ってよね | 你要负责哦 | 你要负责 | 你得负责 |

規則：
- 表格是範圍不是答案。同一功能連續出現三次，第三次必須換寫法，否則像卡帶。
- 粗檔不等於加髒話；粗是**短、硬、不修飾**，不是每句都「他妈」。
- 軟檔不等於加「呢、哦、啦」；軟是**句子短、語氣詞少而準**。

## 2. 描寫四拍

一段 H 描寫按四拍走，缺拍就空，多拍就拖：

```
① 動作（誰對誰做了什麼，一個動作）
② 觸感／聲音（身體感受或水聲、呼吸聲，一個感官細節）
③ 反應（身體或表情的具體變化，不寫「很舒服」）
④ 台詞或旁白收束（一句，短）
```

示範（標準檔）：

> 他扣住她的腰往下按。（①）
> 底下传来黏腻的水声。（②）
> 她的脚趾蜷了起来，喉咙里漏出一声短促的呜咽。（③）
> 「……别、别动。」（④）

反面：
- 四拍全用形容詞（「非常舒服、十分羞恥、無比刺激」）→ 空。
- ③ 寫成「她感到很舒服」→ 抽掉，改成身體做了什麼。
- ④ 太長（超過兩句）→ 收不回來，讀者出戲。

## 3. 節奏與標點

| 規則 | 說明 |
|---|---|
| 一句原文拆 2–3 短句 | 日文用逗號串很長，中文照抄會喘不過氣 |
| 省略號每句最多一處 | 連三個「……」像故障 |
| 呼吸聲用頓號 | 「哈啊、哈啊」比「哈啊哈啊」清楚 |
| 破折號用於打斷 | 被撞斷的話、被摀住的聲音 |
| 不濫用波浪號 | 「啊～」只在角色刻意撒嬌時用 |
| 感嘆號剋制 | H 場景多數是壓抑，不是喊口號 |

## 4. 聲線矩陣（配合 `characters.md`）

| 角色類型 | 用詞特徵 | 要避免 |
|---|---|---|
| 幼／童語 | 短句、疊字、稱呼可愛（小鸡鸡、咪咪） | 突然冒出成年人的性詞 |
| 羞怯／新手 | 停頓多、話說一半、常道歉 | 主動說出粗話（除非墮落線） |
| 傲嬌 | 先否認再洩漏（「才、才不是……」） | 一路順從 |
| 御姐／強勢 | 句子完整、帶命令與評價 | 撒嬌式疊字 |
| 粗漢／粗暴配角 | 短、髒、不修飾 | 突然文藝 |
| 調教者 | 陳述句、少感嘆、多用祈使 | 情緒化喊叫 |
| 被調教者 | 稱呼固定（主人）、應答簡短 | 長篇內心獨白 |
| 男同／女同題材 | 依角色性別定自稱與稱呼，不套異性戀模板 | 把受方一律女性化 |

## 5. 禁忌

1. **不加原文沒有的台詞**：不要為了「更色」補一句呻吟。
2. **不把痛苦譯成享受**（或反之）：凌辱場景的「痛い」就是痛。
3. **不淨化**：原文是「精液」就寫精液，不寫「東西」。
4. **不集體高潮**：不是每段結尾都要絕頂，原文沒到就別加。
5. **不翻譯喘息聲成對話**：「はぁ……」不是「呼……」也不是台詞。
