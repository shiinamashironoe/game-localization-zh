# R18 成人文本翻譯資源庫

> 這是**固定資源庫**，不是臨時參考。遇到 H 場景、凌辱、調教、NTR、風俗店題材時先讀這裡，不要憑感覺現編詞。
> 詞表本身是「語言材料」，用法與一般術語表相同：先定檔位 → 入表 → 全局一致。

## 檔案

| 檔案 | 用途 | 誰讀 |
|---|---|---|
| `lexicon.md` | 核心詞表：部位／行為／液體／狀態／擬聲／關係稱呼，含三層語域與易錯詞 | 人（翻譯前掃一遍） |
| `glossary-nsfw.csv` | 機讀種子表（`原文,簡中,繁中,分層,類別,備註`），直接併入專案 `glossary.md` 或給工具吃 | 腳本／翻譯工具 |
| `dialogue.md` | 台詞句式庫：快感、絕頂、求饒、命令、羞恥、挑逗、事後；描寫四拍與節奏 | 人 |
| `prompt-pack.md` | 可直接貼給 LLM 的 System Prompt、術語注入法、批次流程與一致性抽檢 | 人 |
| `sources.md` | 外部詞典、模型、工具鏈（下ネタ辞典、性風俗用語大辞典、SakuraLLM／GalTransl） | 人 |

## 三層語域（先定，再翻）

| 檔位 | 用在誰身上 | 例（おまんこ） | 例（ちんこ） |
|---|---|---|---|
| 軟 | 童語、撒嬌、第一次、羞怯角色 | 那裡／下面 | 小鸡鸡／那根 |
| 標準 | 一般成人向、旁白、多數女主角 | 小穴／私处 | 肉棒／那话儿 |
| 粗 | 凌辱、痴漢、粗暴配角、調教者 | 骚逼／逼 | 鸡巴 |

- **同一角色全程同一檔位**，除非劇情明確轉變（調教導致墮落、酒後失態），轉變要記進 `characters.md`。
- 旁白與角色台詞可以不同檔位：旁白偏標準、角色偏口語，這是正常的。
- 檔位定案寫進 `style.md` 的「成人內容尺度」，並註明「已確認」。

## 硬規則（違反即不合格）

1. **不審查、不美化、不加戲。** 原文粗俗就粗俗，原文污穢就污穢；把「精液」譯成「那個」、把「交尾」譯成「在一起」都是錯。
2. **不臨床化。** 「陰道／陰莖」只留給醫學、解說、催眠文書、學術旁白；一般 H 場景用「裡面／小穴／肉棒」。
3. **一詞一譯，全局一致。** 定案進 `glossary.md`「成人用詞（R18）」區；要改就全局替換並記變更。
4. **不逐字音譯擬聲詞。** 「ぐちゅ」不是「咕啾」以外的怪字，也不是「guchu」；用中文習慣的水聲／呼吸聲寫法。
5. **不套現代網路梗。** 「社保」「我好了」「牛牛」這類會出戲，除非原作就是現代搞笑調性。
6. **角色聲線優先於詞表。** 同一句「イかせて」：羞怯角色是「让我去吧……」，強勢角色是「让我高潮啊」；詞表給的是範圍，不是唯一答案。
7. **未成年角色標記照原文。** 原文標「ロリ／ショタ／〇歳」就照譯，不迴避也不加碼；不確定時在 `progress.md` 問使用者。

## 併入專案的三步

```bash
# 1) 複製種子表到專案
cp reference/nsfw/glossary-nsfw.csv <遊戲>/_localization/glossary-nsfw.csv

# 2) 只保留本作會用到的列（可選），再轉成工具吃的格式
python scripts/glossary_to_dict.py <遊戲>/_localization/glossary-nsfw.csv --tier 標準 --format arrow

# 3) 把定案詞抄進 glossary.md 的「成人用詞（R18）」表（人看得懂的那份）
```

## 什麼時候不需要本庫

- 全年齡作品、只有擦邊黃段子：照 §3.1 梗註解處理即可。
- 原文本身是醫學／性教育文本：用臨床詞，`lexicon.md` 只取「狀態／擬聲」段。
